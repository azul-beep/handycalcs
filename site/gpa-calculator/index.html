How GPA is calculated

Each letter grade is worth grade points (A = 4.0, B = 3.0, C = 2.0, D = 1.0, F = 0). Multiply the points by the credits of the class, add everything up and divide by the total credits. That is a weighted average: a 4-credit class counts more than a 1-credit class.

Grade points used

A+ and A = 4.0 · A− = 3.7 · B+ = 3.3 · B = 3.0 · B− = 2.7 · C+ = 2.3 · C = 2.0 · C− = 1.7 · D+ = 1.3 · D = 1.0 · D− = 0.7 · F = 0. Some schools give 4.3 for an A+ or use other values; you can also type the number of points instead of the letter (for example "3.5, 3").

Cumulative GPA

To combine with past semesters, enter your current cumulative GPA and the credits you already have. The calculator weighs the old and new credits together.

Weighted GPA

Many high schools add 0.5 or 1 point for honors, AP or IB classes. If yours does, type the boosted number (for example 5.0 for an A in an AP class) instead of the letter.

Frequently asked questions

What is a good GPA?

A 3.0 (B average) is the minimum for many scholarships and programs; 3.5 and above is considered strong for competitive colleges.

How do I write each line?

Course name (optional), grade and credits separated by commas, for example 'Chemistry, B+, 4'. A line like 'A 3' also works.

Do pass/fail classes count?

Usually not. Leave them out unless your school says otherwise.
