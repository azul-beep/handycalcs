WiFi QR Code Generator

Guests point their camera at the code and join your WiFi without typing the password.

🔒 Private: everything happens on your device. Nothing you type or upload is sent anywhere.

How to use it

  1. Type the network name exactly as it appears (upper and lower case matter) and the password.
  2. Choose the security type. Almost all home routers use WPA/WPA2/WPA3.
  3. Download and print it: on the fridge, at the front desk or in a frame on each café table.

Works with iPhone and Android

The iPhone camera (iOS 11 and later) and Android phones (Android 10 and later, or with Google Lens) recognize WiFi QR codes and show a "Join network" button.

Your password stays private

The code is created in your browser. Your network name and password are not sent to us or to anyone. Remember that anyone who scans the code can join the network, so for businesses use a separate guest network.

Frequently asked questions

Why does the phone say it cannot join?

Check that the network name and password are exactly right, including capital letters and spaces, and that the security type matches your router.

Do I need a new code if I change the password?

Yes. The password is written inside the code, so make and print a new one.

Does it work with 5 GHz networks?

Yes. Use the exact name of the network you want guests to join.
