📸PlantillaInstagram que publica soloLa plantilla del video "Mi Instagram publica solo"

Una lista de publicaciones, una rutina gratis de GitHub que la lee todos los días y la API oficial de Meta. Sin programas pagos.

Lo que necesitas (una sola vez)

  1. Instagram en cuenta profesional (creador o empresa), conectado a una página de Facebook.
  2. Una app en developers.facebook.com con permiso para publicar, y un token de página (es la clave; nunca la pegues en un archivo público).
  3. Una cuenta gratis de GitHub y un repositorio nuevo.

Paso 1: la lista (publicaciones.csv)

Una fila por día. La imagen tiene que estar en un link público (por ejemplo, en la misma carpeta del repositorio).

fecha,imagen,texto
2026-12-01,https://TU-SITIO/fotos/01.jpg,"Primer post que se publica solo ✨"
2026-12-02,https://TU-SITIO/fotos/02.jpg,"Segundo post #automatizacion"

Paso 2: el programa (publicar.py)

import csv, datetime, json, os, time, urllib.parse, urllib.request
API = 'https://graph.facebook.com/v21.0'
TOKEN, IG = os.environ['IG_TOKEN'], os.environ['IG_USER_ID']

def pedir(ruta, datos):
    req = urllib.request.Request(f'{API}/{ruta}', data=urllib.parse.urlencode({**datos, 'access_token': TOKEN}).encode())
    return json.load(urllib.request.urlopen(req))

hoy = datetime.date.today().isoformat()
for fila in csv.DictReader(open('publicaciones.csv', encoding='utf-8')):
    if fila['fecha'] == hoy:
        caja = pedir(f'{IG}/media', {'image_url': fila['imagen'], 'caption': fila['texto']})
        time.sleep(20)  # Instagram procesa la imagen
        print(pedir(f'{IG}/media_publish', {'creation_id': caja['id']}))

Paso 3: la rutina diaria (.github/workflows/publicar.yml)

name: Publicar en Instagram
on:
  schedule:
    - cron: '0 18 * * *'   # todos los días 18:00 UTC
  workflow_dispatch:
jobs:
  publicar:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python3 publicar.py
        env:
          IG_TOKEN: ${{ secrets.IG_TOKEN }}
          IG_USER_ID: ${{ secrets.IG_USER_ID }}

Paso 4: las claves

En GitHub: Settings → Secrets and variables → Actions → New repository secret. Crea IG_TOKEN y IG_USER_ID. Listo: cada día publica la fila de esa fecha.

Ojo: GitHub puede atrasar las rutinas programadas unos minutos u horas. Para Facebook es igual, cambiando la dirección a /PAGINA_ID/photos.

📌Paso a pasoPinterest que se llena soloEl paso a paso del video del RSS
  1. Pasa tu Pinterest a cuenta de empresa (es gratis) y reclama tu web en Configuración → Cuentas reclamadas.
  2. Busca el RSS de tu web. En WordPress es tuweb.com/feed; en Shopify, tuweb.com/blogs/news.atom; en Blogger, tuweb.blogspot.com/feeds/posts/default.
  3. Asegúrate de que cada artículo tenga una imagen vertical (2:3, por ejemplo 1000×1500). Es la que se va a ver como pin.
  4. En Pinterest: Configuración → Publicación masiva → Conectar RSS. Pega el link y elige el tablero.
  5. Listo. Cada artículo nuevo se convierte en pin solo, una vez por día.

Puedes conectar hasta 200 RSS, uno por tablero. Usa uno por tema para que cada pin caiga en el tablero correcto.

🏷️Prompts3 prompts para tu tiendaTítulo, descripción y etiquetas (sirven para Etsy y otras tiendas)

1. Título

Eres experta en SEO de Etsy. Mi producto es: [qué es, para quién, material, ocasión].
Escribe 5 títulos de menos de 140 caracteres. Empieza con las 2 o 3 palabras que más busca la gente para este producto, después el detalle que lo diferencia. Nada de mayúsculas sostenidas ni emojis.

2. Descripción

Escribe la descripción de este producto: [pega el título y los datos].
Las 2 primeras líneas dicen qué es y para quién (se ven en Google). Después responde en lista las dudas que tendría un comprador: medidas, material, cuidado, envío, personalización. Tono cálido y claro. No inventes datos: si te falta uno, pregúntamelo.

3. Las 13 etiquetas

Dame 13 etiquetas para este producto: [título].
Máximo 20 caracteres cada una, frases de 2 o 3 palabras como las escribe un comprador, sin repetir palabras que ya están en el título. Mezcla: para quién es, ocasión, estilo y regalo.

Revisa siempre medidas y materiales: la IA a veces inventa detalles.

📊PlantillaLa planilla que te avisa si algo se rompeGoogle Sheets + un script gratis
  1. Crea una planilla de Google. En la columna A, desde la fila 2, pega los links de tus webs y tiendas.
  2. Menú Extensiones → Apps Script. Borra lo que haya y pega esto:
function revisar() {
  const hoja = SpreadsheetApp.getActiveSheet();
  const filas = hoja.getRange(2, 1, hoja.getLastRow() - 1, 1).getValues();
  const rotos = [];
  filas.forEach(([url], i) => {
    if (!url) return;
    let codigo;
    try { codigo = UrlFetchApp.fetch(url, { muteHttpExceptions: true, followRedirects: true }).getResponseCode(); }
    catch (e) { codigo = 'sin respuesta'; }
    hoja.getRange(i + 2, 2, 1, 2).setValues([[codigo, new Date()]]);
    if (codigo !== 200) rotos.push(url + ' → ' + codigo);
  });
  if (rotos.length) MailApp.sendEmail(Session.getActiveUser().getEmail(), '⚠️ Algo se rompió', rotos.join('\n'));
}

function resumenSemanal() {
  const filas = SpreadsheetApp.getActiveSheet().getDataRange().getValues().slice(1);
  const texto = filas.map(([url, codigo]) => (codigo === 200 ? '✅ ' : '❌ ') + url).join('\n');
  MailApp.sendEmail(Session.getActiveUser().getEmail(), 'Resumen de la semana', texto);
}
  1. Guarda y toca Ejecutar una vez con revisar para darle permiso.
  2. En el reloj de la izquierda (Activadores): agrega revisar cada hora y resumenSemanal los lunes a la mañana.
💬PromptsRespuestas rápidas a clientesEl prompt y mis respuestas

El prompt

Tengo una tienda de [qué vendes]. Estas son las 5 preguntas que más me hacen: [pégalas].
Escribe una respuesta corta (máximo 3 líneas) y amable para cada una, que termine invitando a comprar o a preguntar más. Usa mis datos reales: envío [días], cambios [política], personalización [sí/no].

Ejemplos de respuestas

¿Cuánto tarda el envío?
¡Hola! Se prepara en 2 a 5 días hábiles y después tarda entre 3 y 7 días en llegar. Te paso el número de seguimiento apenas salga 😊
¿Se puede personalizar?
¡Sí! Escríbeme el nombre o la frase que quieres y te muestro cómo queda antes de hacerlo.
¿Hacen cambios?
Si llega con algún problema, escríbeme con una foto y lo solucionamos. Los productos personalizados no tienen cambio, por eso te muestro la prueba antes.

Dónde guardarlas

  • Instagram: Configuración → Herramientas para empresas y creadores → Respuestas guardadas.
  • Etsy: Mensajes → Respuestas guardadas.
  • WhatsApp Business: Herramientas para la empresa → Respuestas rápidas.
📚Paso a pasoTu libro en Amazon con ayuda de IALos pasos del video del libro de sopas de letras
  1. Tema: busca en Amazon libros de actividades (sopas de letras, sudoku, colorear) y mira los que tienen muchas reseñas. Elige un tema más específico: letra grande, un hobby, una edad.
  2. Interior: pídele a la IA un programa que arme las páginas (por ejemplo, en Python) y te dé un PDF del tamaño del libro, con las soluciones al final.
  3. Portada, título y descripción: la portada se arma con la plantilla de tamaño que da Amazon KDP; el título dice qué es y para quién.
  4. Subirlo: en kdp.amazon.com, crea el libro de tapa blanda, sube el interior y la portada, y en la pregunta de contenido con IA marca Sí en lo que corresponda.
Prompt para el título: Mi libro es [tipo] para [quién]. Dame 10 títulos con subtítulo que digan exactamente qué hay adentro y para quién, usando las palabras que la gente busca en Amazon.

Amazon permite crear un número limitado de libros nuevos por semana. Ve de a poco.

🚀Para empezarTu primera automatizaciónSi nunca automatizaste nada, empieza aquí
  1. Elige una tarea que repites todas las semanas (publicar, contestar, pasar datos).
  2. Escribe los pasos como una receta, uno por línea.
  3. Busca qué la dispara: una hora, un mail que llega, un formulario que alguien llena.
  4. Pégale todo eso a la IA con este prompt:
Quiero automatizar esta tarea sin pagar herramientas: [la receta]. Se dispara cuando [disparador].
Dime qué herramienta gratis usar (Google Apps Script, GitHub Actions, Zapier gratis, etc.) y dame los pasos uno por uno, como si nunca hubiera programado.
